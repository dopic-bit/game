# ОЧЕРЕДЬ 🥖

Игра про очередь на чистом C++17. Ты — человек, который очень хочет в начало
очереди, а очередь — очень против. Физика людей, толчки, локти, бабушка с
авоськой массой 1.9. Смешно и зло.

## Сборка и запуск

```bash
g++ -std=c++17 -O2 -o queue queue_game.cpp
./queue
```

Нужен терминал минимум 80×23 и Linux/macOS/WSL.

## Управление

| Клавиша | Действие |
|---|---|
| `a` / `d` | двигаться влево / вправо (к кассе) |
| `SPACE` | ТОЛЧОК — вперёд тому, кто стоит впереди (−12 сил) |
| `b` | ЛОКТИ назад — отбиться от лезущего сзади |
| `p` | УПРЕТЬСЯ — стать неподвижной глыбой (масса ×10) |
| `q` | выйти |

## Цель

Дойти до `[ КАССА ]` и пробить чек — победа. Тебя вытолкнули к левому краю
очереди — поражение. Рекорд сохраняется в `~/.queue_records`.

## NPC

- `B` Бабушка с авоськой — масса ×1.9, почти неподъёмная
- `S` Школьник — лёгкий, но шустрый
- `T` Тёзка с телефоном, `D` Дед-фантик, `K` Курьер, `P` Программист

Злость NPC растёт сама и от твоих действий: перезарядилась — толкает,
дозрела — идёт на прорыв.
